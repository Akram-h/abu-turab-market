# إجابات نماذج المتاجر (ملخّص جاهز)

## Google Play — Data safety
| السؤال | الإجابة |
|---|---|
| هل يجمع التطبيق أو يشارك بيانات المستخدم؟ | يجمع (لا يشارك مع أطراف أخرى، لا إعلانات) |
| أنواع البيانات | الاسم، معرّفات الحساب (اسم المستخدم)، رقم الهاتف (ولي الأمر والمعلم)، سجلات تعليمية (حضور/درجات/تقييمات)، معلومات الأقساط |
| هل البيانات مشفّرة أثناء النقل؟ | نعم (HTTPS) |
| هل يمكن طلب حذف البيانات؟ | نعم عبر المدرسة أو البريد في سياسة الخصوصية |
| الغرض | وظائف التطبيق (إدارة الحساب والمتابعة الدراسية) |
| المستخدمون المستهدفون | البالغون (أولياء الأمور والمعلمون والإداريون) — لا تستهدف الأطفال |
| الإعلانات | لا |
| تقييم المحتوى | الجميع / تعليمي |
| رابط سياسة الخصوصية | ارفع privacy-policy.html وضع رابطه |
| حساب تجريبي لمراجعي Google | أنشئ مدرسة تجريبية وحساب ولي أمر وضعه في App access |

## Apple — App Privacy (Nutrition Label)
- Data linked to user: Name, Phone Number, User ID, Other User Content (grades/attendance), Financial Info → "Other Financial Info" (school fees records)
- Used for: App Functionality فقط. Tracking: لا. Third-party advertising: لا.
- Age rating: 4+ (لا محتوى حساس). التصنيف: Education.

## ملاحظة عن مراجعة Apple
تشدد Apple على ألا يكون التطبيق مجرد موقع معبّأ. هذا التطبيق يحمل واجهته داخل الحزمة ويتصل بالخادم عبر واجهة برمجية، ويستعمل مشاركة الملفات الأصلية وزر الرجوع. هذا يحسّن فرصه لكنه **لا يضمن القبول**؛ قد تطلب Apple تعديلات.
